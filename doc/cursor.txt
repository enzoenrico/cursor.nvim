*cursor.txt*    A Neovim extension for the Cursor agent CLI           *cursor.nvim*

==============================================================================
INTRODUCTION                                                  *cursor-intro*

cursor.nvim wraps the `cursor-agent` CLI so you can talk to Cursor agents
without leaving Neovim. The plugin is pure Lua and uses |jobstart()| to spawn
the CLI and parse its `stream-json` output.

Requirements:
  - Neovim 0.10+
  - `cursor-agent` on $PATH (https://docs.cursor.com)

==============================================================================
QUICK START                                                  *cursor-setup*

>
    require("cursor").setup({
      cmd     = "cursor-agent",
      model   = nil,         -- nil = SDK default
      keymaps = true,        -- <leader>c* defaults
      ui      = {
        layout = "right",    -- "right" | "left" | "top" | "bottom"
        width = 30,
        winborder = "rounded",
      },
      notify  = true,
    })
<

Open the sidebar with |:CursorToggle| or |:CursorChat|.

==============================================================================
SIDEBAR                                                         *cursor-sidebar*

The sidebar is a split layout: transcript (top) and prompt input (bottom).
Optional selected-code panel when using |:CursorEdit|.

Prompt input:
  <CR> (normal) / <C-s> (insert)  submit
  @                               attach file context
  ,c                              manage context files
  <Tab>                           switch transcript ↔ input
  q / <C-c> (normal)              close sidebar
  /clear, /new, /compact          slash commands
  /skills, /skill <name>          list or attach agent skills
  /<skill-name> [prompt]          invoke a skill (Cursor SKILL.md)
  ,s                              manage attached skills

Transcript:
  ]] / [[                         next / previous message
  a / A                           apply code block(s) from latest reply

Conflict markers in code buffers (`<<<<<<< HEAD` / `>>>>>>> Cursor`) enable
diff keymaps automatically (see |cursor-diff|).

==============================================================================
COMMANDS                                                  *cursor-commands*

Sidebar~
  |:CursorToggle|     Toggle sidebar
  |:CursorChat|       Open sidebar
  |:CursorFocus|      Toggle focus code ↔ sidebar
  |:CursorNew|        New conversation
  |:CursorZen|        Zen mode (minimize code window)
  |:CursorHistory|    Browse saved conversations
  |:CursorModel|      Pick a model

Prompting~
  |:CursorAsk| {prompt}
                  Open sidebar, fill prompt, and submit

Agent~
  |:CursorStop|       Cancel running agent
  |:CursorStatus|     Echo { running, agent_id, model }

Diff~
  |:CursorApply|      Resolve conflict at cursor
  |:CursorApplyAll|   Accept all incoming in buffer

Meta~
  |:CursorVersion|    Print version to |:messages|
  |:checkhealth cursor|  Verify CLI and environment

==============================================================================
DIFF KEYMAPS                                                  *cursor-diff*

When conflict markers are present in a normal buffer:

  co    keep current (ours)
  ct    keep incoming (theirs)
  ca    accept all incoming
  cb    keep both
  ]x    next conflict
  [x    previous conflict

Configure under `diff` in |setup()|.

==============================================================================
HEALTH                                                       *cursor-health*

>
    :checkhealth cursor
<

Reports whether `cursor-agent` is on $PATH and whether |vim.json| is available.

==============================================================================
LUA API                                                          *cursor-api*

require("cursor").setup({opts})
require("cursor").ask(prompt)          Open sidebar and submit
require("cursor").chat()               Open sidebar
require("cursor").toggle()
require("cursor").focus()
require("cursor").new_chat()
require("cursor").edit()               Edit visual selection
require("cursor").stop()
require("cursor").status()             { running, agent_id, model }
require("cursor").version()
require("cursor").history()
require("cursor").select_model()
require("cursor").zen()

require("cursor.agent").start({opts})  Lower-level CLI streaming API.

==============================================================================
KEYMAPS                                                     *cursor-keymaps*

With `keymaps = true`:

  <leader>ct   toggle sidebar
  <leader>cf   focus
  <leader>cc   chat
  <leader>ca   prompt then ask
  <leader>cn   new chat
  <leader>ce   edit selection
  <leader>ch   history
  <leader>cm   model
  <leader>cz   zen
  <leader>cb   add buffer to context
  <leader>cs   stop
  <leader>c?   status
